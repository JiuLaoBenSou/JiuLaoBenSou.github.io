隐私政策

更新日期：2026-10-29。适用于本网站的阅读页面；GitHub 等外部服务另按其政策处理数据。

Cookie

当前本站页面不主动设置 Cookie，不使用 localStorage 或其他追踪存储。点击外部链接并访问 GitHub 等服务后，对方可能使用 Cookie；这由相应服务的隐私设置管理。

广告与个性化广告

本站目前未使用 Google AdSense 或其他广告平台，也未加载广告脚本。若以后启用 Google 广告，Google 及其合作伙伴可能依据此前访问本站或其他站点的记录投放广告，届时会先更新本政策并按适用要求提供选择。

Google 个性化广告可在Google 广告设置中关闭；该入口是外部服务。

分析工具与保留时长

本站未使用 Google Analytics、Cloudflare Analytics 或自建分析工具；维护者不收集、不建立个人访问分析记录，因此没有此类分析数据的保留期。

GitHub Pages 托管服务会为安全目的记录访问者 IP 地址。其处理及保留依 GitHub 政策决定，本站无法指定或确认固定天数，不将它说成零留存。参见GitHub Pages 数据说明及GitHub 隐私声明。

数据处理方式

这是静态阅读网站，没有文件上传、账号注册或服务器处理表单；本站不上传读者文件。文章、SVG 封面及字体以静态资源提供，阅读排版在浏览器本地完成。普通网页访问仍会向 GitHub Pages 请求资源，不等于浏览全程没有网络记录。

评论与联系

Giscus 评论尚未启用，没有嵌入脚本或 iframe。联系页面仅链接 GitHub Issues；主动提交的反馈由 GitHub 保存并公开展示，保留与删除遵循其平台规则。请勿在公开反馈中提交敏感信息。

需要提出隐私相关请求，请通过联系页面联系维护者。
